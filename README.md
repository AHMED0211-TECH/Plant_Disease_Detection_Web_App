# AI Based Plant Disease Detection Web App

## Overview
A full stack web application that detects plant diseases 
from leaf images using deep learning — built for farmer use 
on local networks.

## Key Stats
- Trained on 54,000+ leaf images
- 38 disease classes
- 85%+ test accuracy

## Tech Stack
- Python
- PyTorch
- OpenCV
- Flask
- React (Frontend)

## Features
- Upload leaf image via browser
- Instant disease prediction
- Mobile friendly UI
- Accessible on local network (LAN)

## How It Works
1. User uploads leaf photo via React frontend
2. Flask API receives and processes image
3. CNN model predicts disease class
4. Result displayed instantly on screen
